# Terminal Game in C

**Course:** Unix and C Programming (Curtin University)

**Overview**
This repository contains a modular, terminal-based game written in C. The project demonstrates core Unix environment skills, including manual memory management, modular compilation, and low-level system interactions.

**Technical Skills Demonstrated**
* **Language:** C
* **Data Structures:** Custom linked list implementation (`linkedlist.c`).
* **Concepts:** File I/O parsing (`file_io.c`, `map.txt`) and terminal UI manipulation (`terminal.c`, `color.c`).
* **Tools:** Custom `makefile` for automated compilation.
